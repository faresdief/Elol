# Elol | BARBER HOUSE

موقع محل حلاقة BARBER HOUSE في مصر القديمة: الخدمات والأسعار، سلة طلبات، والتواصل عن طريق واتساب. Website for BARBER HOUSE barbershop in Old Cairo: services and prices, an order cart, and contact over WhatsApp.

**Live demo:** https://faresdief.github.io/Elol/

## المميزات | Features

- قائمة الخدمات والأسعار: حلاقة شعر، دقن، وعناية بالبشرة. Services and prices: haircuts, beard trims, and skin care.
- سلة طلبات بتجمع الخدمات اللي اخترتها قبل الإرسال. A cart that collects your chosen services before sending.
- إرسال الطلب على واتساب المحل بضغطة واحدة. Send the order to the shop's WhatsApp in one tap.
- زرار موقع بيفتح عنوان المحل على Google Maps. A location button that opens the shop's address in Google Maps.
- صفحة واحدة `index.html` بالعربي (RTL). A single-page Arabic RTL site.

## التشغيل | Run

افتح `index.html` في المتصفح، أو ارفع الملفات على GitHub Pages. Open `index.html` in a browser, or host it on GitHub Pages.
